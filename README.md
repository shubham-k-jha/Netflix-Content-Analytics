# 📌 Overview

**Netflix Content Intelligence v8.1** is a production-style, source-driven analytics project designed to transform Netflix's published Top 10 data into a complete analytical system.

Instead of treating the project as a static dashboard or notebook, the system follows an end-to-end workflow:

```text
Official Netflix Sources
        ↓
Raw Data Ingestion
        ↓
Data Validation
        ↓
Normalization
        ↓
Analytical Data Modeling
        ↓
SQL Analytics
        ↓
Statistical Analysis
        ↓
Lifecycle & Market Intelligence
        ↓
Forecasting & Machine Learning
        ↓
Reports + SQLite
        ↓
Interactive Streamlit Dashboard
